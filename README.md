# Tutoraan – Tutor & Student Platform

## Project Overview

**Tutoraan** is a full-stack tutor-student platform designed to connect students with suitable tutors based on their educational requirements, location, and preferences.

The platform includes mobile applications for Android and iOS, web-based dashboards, real-time communication, tutor discovery, lead management, and analytics.

### Application Availability

- **iOS:** [View on Apple App Store](https://apps.apple.com/us/app/tutoraan/id6770827316)
- **Android:** Android application developed; currently unavailable on Google Play.

## Key Features

### 1. Tutor Discovery & Search
- Tutor discovery based on requirements, location, and relevant criteria.
- Tutor profile management.
- Student tutor request and lead generation workflows.

### 2. Authentication & Authorization
- Role-based authentication for students and tutors.
- Secure API access and request validation.

### 3. Real-Time Chat
- Tutor-student communication workflows.
- Real-time messaging and conversation management.

### 4. Lead Management & Analytics
- Lead generation and tracking.
- Tutor dashboard analytics.
- Lead conversion monitoring and performance insights.

### 5. Redis & BullMQ
- Redis integration for caching and performance optimization.
- BullMQ integration for background job processing.
- Asynchronous task processing to support backend workflows.

### 6. Dashboard Development
- Developed web dashboards using React.js, TypeScript, and Tailwind CSS.
- Integrated backend APIs for tutor profiles, requests, leads, and analytics.
- Implemented role-based dashboard functionality.

### 7. Mobile Application Integration
- Backend API integration for Android and iOS applications.
- Mobile deep linking support.
- Shared backend services for mobile and web platforms.
